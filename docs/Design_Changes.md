# Design Changes

## Tool Bar Button Changes

Currently the Bookmarking, Managaing Bookmarks, and Exporting are three separate buttons. Please group them like the back forward and refresh buttons are.

## Tool Bar Title

Right now, to the left of the URL field, there is a title. This is not needed. Please remove it to get some space back in the toolbar. The URL field is enough for a user to know where they are. The URL field should remain the same length it is now. One goal is to avoid the overflow icon (>>) when there is not enough space on the toolbar for all the buttons.
